# Number Guessing Game in C

My second project using the C programming language.

## About
A command-line guessing game where the computer generates a random number between 1 and 100.

The player gets three attempts to guess the number.

## Features
- Random number generation (1-100)
- Three guessing attempts
- Too high / Too low feedback
- Hint after two incorrect attempts
- Reveals the correct answer if the player loses

## Concepts Practiced
- Variables and data types
- For loops
- If-else statements
- Logical operators
- Random number generation
- Break statement
- User input and output

## Language
C

## What I Learned
I learned how to generate random numbers, use loops to control attempts, compare user input, and implement a hint system.
